# 圖片 GPS 擷取工具

以 Windows 內建 OCR 讀取目錄中的圖片，將畫面上的十進位 GPS 座標轉成收藏地點 JSON。不讀取 EXIF GPS，不會將圖片上傳網路。

## 環境

- Windows 10 2004 以上或 Windows 11。
- .NET 10 SDK。
- Windows 繁體中文 OCR 語言（`zh-Hant-TW`）。若未安裝，程式會顯示錯誤及可用語言；請從 Windows「設定 > 時間與語言 > 語言與地區」新增繁體中文並安裝文字辨識／基本輸入功能。
- 首次建置需要還原 Windows SDK 的 NuGet 參考套件，OCR 執行本身不需連網。

## 使用方式

在專案目錄執行：

```powershell
dotnet run
```

預設掃描 [Input](Input) 中的 PNG、JPG、JPEG、BMP、TIF、TIFF，結果寫入 [Output](Output)。也可以指定路徑：

```powershell
dotnet run -- "C:\我的圖片" "C:\GPS結果" --recursive
dotnet run -- "C:\我的圖片" "C:\GPS結果" --language en-US
```

`--recursive` 包含子目錄；預設不包含。每張圖片可擷取多組座標，順序為檔名排序後的 OCR 文字順序，不自動去除重複地點。

無法辨識文字、找不到座標或座標超出有效範圍的圖片，會移至執行時目前目錄下的 `Check`，供人工檢查；同名檔案會加上隨機後綴，不覆蓋既有圖片。掃描時排除 `Check` 內的圖片。讀檔／OCR 系統錯誤不移動圖片；移動失敗會明確記錄錯誤。需要重試時，請將圖片移回 `Input`。

## 輸出

- `GPS.json`：JSON 陣列，每組座標一筆，數字不是字串，UUID 為每筆隨機產生的 UUID v4。
- `errors.json`：失敗圖片原路徑、原因、已辨識文字及移動後的 `check_file` 路徑（未移動為 `null`）；無錯誤時為 `[]`。
- `ocr.json`：成功完成 OCR 的原始辨識文字，供人工核對；可能包含畫面中的其他個人資訊，請妥善保管。

```json
[
  {
    "marker_uuid": "54816475-9076-4944-ab1e-e42ecbfb8f84",
    "marker_latitude": 35.220923,
    "marker_longitude": 138.697007,
    "marker_is_favorite": true,
    "marker_favorite_title": "花點",
    "marker_favorite_description": ""
  }
]
```

`marker_favorite_description` 只填入 `#Tag`，保留 `#`，多個標籤以空格分隔並去除重複，例如 `"#新加坡 #清真寺 #花點"`；沒有標籤時輸出空字串 `""`，不填入一般描述文字。支援中文、英文字母、數字、底線及全形 `＃`。每組座標擷取其後到下一組座標之前的標籤；第一組另外包含圖片開頭到座標之前的標籤。這是依 OCR 閱讀順序分段，若圖片將每筆標籤放在座標之前，請人工核對歸屬。

分類仍參考座標附近的文字：優先取座標後的 `#標籤`，否則第一組取座標前最近的非介面文字，其餘取後方第一行。分類優先檢查這些文字中的花點／菇類文字，再參考整張圖片的「菇」或「茹點」文字；沒有蘑菇線索時預設「花點」。依需求，蘑菇類輸出標題使用「茹點」，也可辨識原文「菇點」。會合併 OCR 在中文字間插入的空格，並接受數字間被誤辨成「·」的小數點。

這是文字規則而非圖像內容分類：純粹出現花朵或蘑菇的圖案，不一定能正確分類；複雜版面、混合多類地點或模糊圖片請核對 `ocr.json` 和結果。座標必須為「緯度, 經度」，兩個數字均含小數點，支援負號及全形標點；不支援度分秒、經緯顛倒或只有 EXIF 的圖片。緯度須在 -90 至 90、經度在 -180 至 180，無效座標會將該圖片記為失敗。

**每次執行會覆寫上述三個輸出檔並重新產生 UUID**，如需保留結果請使用不同輸出目錄。沒有圖片或初始化失敗時不修改既有輸出。單張圖片失敗會繼續處理其他圖片，並輸出成功部分；退出碼：`0` 全部成功、`2` 部分或全部圖片失敗、`1` 設定／檔案系統錯誤。

## 測試

```powershell
dotnet test .\Tests\GpsImageExtractor.Tests.csproj
```

涵蓋兩張範例的 OCR 文字、全形標點、負經度、多組座標、範圍檢查、UUID、JSON 欄位及目錄掃描。實際 OCR 需另以 `dotnet run` 在安裝辨識語言的 Windows 上驗證。
